# assets/

A scratch shelf for **inspiration and reference material** gathered while designing the *Badger*
addons — screenshots of other unit-frame / on-screen-info UIs, mock-ups, colour and layout ideas,
and articles or documents worth keeping. It is a mood board, not part of any addon.

This folder is **outside `projects/`**, so nothing here is ever bundled into an addon build — the
packager only touches the addon under `projects/`.

## Layout

- **`images/`** — pictures: screenshots, UI references, mock-ups, colour studies.
- **`documents/`** — longer references: PDFs, saved articles, notes.

Drop files straight in; organise into subfolders if a theme builds up. When a reference comes from a
URL, jot the source next to the file (or in a short note) so we can find it again.

## Ground rules

- **References, not shipped assets.** Everything here is for inspiration only. Images and documents
  pulled from the internet stay under their original copyright — we do **not** redistribute them in
  any addon. Real in-game art is authored separately and lives with its addon under `projects/`.
- **Keep files reasonably sized.** They're committed directly to git (no Git LFS). Prefer compressed
  screenshots over multi-megabyte originals; trim or link out to anything large.
