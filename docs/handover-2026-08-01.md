## The regime layer in one paragraph

An injected, read-only per-encounter table (`opts.regime`) consumed by **nil-guarded seams inside
`estimator.lua`**; with `regime == nil` the estimator is **byte-identical** to before, which is enforced by
diffing `tools/estimator-sim.lua` against `main` on every PR. Profiles live in
`src/raids/regimes.lua` — **auto-generated**, never hand-edited. The confidence caps that make the bar go
quiet are **learned from the estimator's own measured per-bin error** over ~900 real kills, so "this fight is
unreadable" is a measurement, not an opinion. Headline: **Buru 188.6%→37.3%**, Twin Emperors 407%→**silent**,
and two bosses (Chromaggus, Ouro) measured as readable correctly got **no caps at all**.

## The lab (all client-side, never in CI)

```sh
export PATH="$HOME/.luarocks/bin:$PATH"          # REQUIRED — luacheck/busted/luajit live here
python3 tools/wcl-corpus.py <freshEncId> --n 60  # harvest real kills  (Fresh id = classic id + 150000)
python3 tools/learn-regime.py <id> --split-even  # learn caps from measured error (+ --suppress-flush)
python3 tools/assemble-regimes.py                # candidates + hand facts -> src/raids/regimes.lua
python3 tools/grade-regimes.py                   # held-out baseline vs SHIPPED, MAPE *and* shown%
luajit  tools/estimator-batch.lua <dir> --shipped # grade what actually ships
pnpm validate                                    # the gate (stylua · luacheck · busted)
```

`tools/fights/corpus/` is **gitignored and disposable** (~920 fixtures right now — Onyxia ×200 plus 12 bosses
×60). The WCL API key is in a gitignored `.env`. Never run harvesting/learning in CI.

## Three lessons this session paid for (don't re-learn them)

1. **Measure the thing itself, not a proxy.** Caps were nearly derived from the dispersion of remaining time;
   its denominator vanishes as a fight ends, so it would have silenced the **endgame** — the stretch the bar
   gets *most* right (~3s error with 10s to live). Measuring the estimator's own error has no such artifact.
2. **A blanket default must not override a measurement.** Folding the universal cap into a *measured* boss
   silenced Chromaggus' most readable band and made his grade worse. Defaults are for the un-measured.
3. **Learn under the configuration that ships.** Caps derived without a boss's own categorical facts are
   calibrated against an estimator that never runs (Buru ~3× worse, Thekal ~1.5×) and over-silence a usable
   readout.

## Working agreement reminders (they bit during this session)

- Docs under `docs/` are free to edit; **everything else needs explicit acceptance**, lands on a branch, and
  reaches `main` only via a PR **the human merges**. The AI never merges.
- **Work-order files live-mirror to `main`** (no branch/PR); the *code* they drive does not.
- A version bump is a **deliberate release act**; conventional commits only decide *how much* to bump.
- On 0.x, Nx adjusts a `minor` bump downward — which is why `feat:` commits landed on **0.9.48**, not 0.10.0.
